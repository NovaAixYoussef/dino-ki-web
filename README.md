# DINO KI – Neuronales Netzwerk spielt Google Dino

Wissenschaftliche Projektdokumentation: Ein NEAT-Netzwerk lernt autonom, das Google-Dino-Spiel zu spielen.

## Inhalt der Webseite
- Projekt-Überblick & Steckbrief
- Das Spiel (Screenshots aus echten Spieldaten)
- 6 Eingabedaten des Netzwerks
- Netzwerk-Architektur (6 → 6 → 2) mit Live-Visualisierung
- Mathematisches Modell (gewichtete Summe, tanh/sigmoid/relu)
- Beispiel-Entscheidung
- Training mit NEAT (Evolution, Mutationen)
- Fitness-Funktion
- Ergebnisse & Code-Übersicht

## Technik
Python 3.14 · pygame-ce 2.5.8 · neat-python · pygame-menu 4.5.2 · Manim · C++-Portierung
